# Измеритель нагрузки по светодиоду счётчика

Android-приложение: по частоте вспышек красного светодиода импульсного выхода
счётчика (НАРТИС-И100, C = 500 imp/kWh) показывает мощность и ток.

## Сборка

Проект собирается в GitHub Actions. Достаточно запушить папку в репозиторий
(ветка `main`) — готовый APK появится в артефактах под именем `Meter-debug-apk`.

- [x] Шаг 0. Скелет проекта, сборка, запуск
- [x] Шаг 1. Превью камеры, тап по светодиоду, фиксация AF/AE
- [ ] Шаг 2. Детектор импульсов и цифры на экране
- [ ] Шаг 3. Настройки: константа, напряжение, номинал автомата
- [ ] Шаг 2.5 (позже). Второй ROI на реактивном светодиоде -> честный ток (S = √(P²+Q²))

## Расчёты

P [кВт] = 3600 / (C * T) = 7,2 / T   (C = 500)
I [А]   = P * 1000 / (230 * cosφ) ≈ 4,35 * P

## Шаг 1: что сделано

- Разрешение `CAMERA`, экран не гаснет.
- Превью CameraX на весь экран, `FIT_CENTER` (виден весь кадр 4:3 целиком).
- `ImageAnalysis` 640x480, RGBA_8888, аспект 4:3, `AE_TARGET_FPS_RANGE` = 30 fps.
- Тап по превью -> рамка ROI (64x64 px) на верхнем светодиоде + фиксация AF/AE.
- ROI хранится в нормированных координатах и запоминается между запусками.
- Отладочный HUD: координаты ROI, поворот кадра, фактический FPS, статус.
